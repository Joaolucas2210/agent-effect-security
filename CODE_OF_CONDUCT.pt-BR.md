# Código de Conduta

[English](CODE_OF_CONDUCT.md) · **Português (Brasil)**

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)
como código de conduta. Todos que participam de issues, pull requests, discussions e revisões devem segui-lo.

## Como reportar

Reporte comportamento inaceitável em privado ao mantenedor, [@Joaolucas2210](https://github.com/Joaolucas2210), pelo
contato listado nesse perfil do GitHub. Os reportes são tratados com confidencialidade. Vulnerabilidades de
segurança seguem o [SECURITY.pt-BR.md](SECURITY.pt-BR.md).

## Aplicação

O mantenedor aplica as
[diretrizes de aplicação](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/#diretrizes-de-aplica%C3%A7%C3%A3o)
do Contributor Covenant: correção, advertência, banimento temporário e banimento permanente, proporcionais ao
comportamento.
