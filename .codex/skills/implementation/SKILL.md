# Generic Implementation

Use only after discovery and planning.

## Rules

- Make the smallest possible diff.
- Preserve existing behavior.
- Follow the project's patterns.
- Avoid broad refactors.
- Add tests when there is business logic.
- Do not add dependencies without need.
- Do not expose secrets or PII.

## Expected output

- Changes made
- Files changed
- Technical notes
