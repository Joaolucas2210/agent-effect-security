# Generic Test Review

Use after implementation.

## Checklist

- Run the available tests.
- Run lint when available.
- Run the build when available.
- Run the typecheck when available.
- Run `docker compose config` when applicable.
- Review the diff.
- Report validations that could not be run.

## Expected output

- Commands run
- Result
- Problems found
- Fixes made
